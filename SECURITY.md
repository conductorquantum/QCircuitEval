# Security Policy

The `main` branch is the supported release surface.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting on this repository:
**Security → Report a vulnerability**.

Do not file a public issue for an exploitable defect in the grader, providers,
or AWS production runners. We will acknowledge the report and say whether we
can reproduce it.

Ordinary benchmark bugs, contract mistakes, and documentation fixes belong in
public issues or pull requests.

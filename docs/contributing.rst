Contributing
============

QCircuitEval accepts pull requests, including changes to the grader:
contracts, targets, verifier engines, framework lowering, and hard
requirements.

The maintained checklist is ``CONTRIBUTING.md`` at the repository root.
GitHub shows that file on new pull requests. Do not duplicate it here.
Community participation follows ``CODE_OF_CONDUCT.md``. Security reports
follow ``SECURITY.md``.

See :doc:`grader` for local regrade and contract design, and :doc:`cli` for
``--regrade`` / ``--input``.
